# Workflow: Feature Build

## Objective
Manages the process of adding a new feature from scratch or onto an existing module. Works in harmony with your existing skills.

## Steps
1. **Discovery:** Inspect the relevant codebase and understand existing patterns. Ask if any requirements are missing.
2. **Planning (Mandatory):** Writing code directly is **FORBIDDEN**. First, present a brief implementation plan detailing affected and new files, and **wait for my approval**.
3. **Execution:** Once approved, write the code. Actively utilize your existing skills (code formatting, type-checking, etc.) during development.
4. **Verification:** Run the project's test and linter skills/commands to ensure everything is error-free.
5. **Handoff:** Provide a summary of the modified and created files.
