# Workflow: Bugfix & Debugging

## Objective
Defines the flow to follow for resolving a bug report or fixing unexpected behavior.

## Steps
1. **Analysis:** Analyze the bug report and stack trace. Do not touch the code until you identify the root cause.
2. **Hypothesis / Plan:** Present a brief hypothesis and plan on how you will fix the bug. Get approval.
3. **Fix & Test:** Apply the fix. If possible, add a regression test to prevent the bug from recurring.
4. **Verification:** Run tests to confirm that the bug is fully resolved.
