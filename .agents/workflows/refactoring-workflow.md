# Workflow: Refactoring

## Objective
The process of improving the internal structure of existing code without changing its external behavior (behavior-preserving).

## Steps
1. **Baseline Check:** Ensure that the tests for the target code are currently passing (green).
2. **Scope & Plan:** Specify the files to be refactored and the target improvement (clean code, performance, readability). Present a plan.
3. **Execution:** Perform the refactoring step-by-step.
4. **Regression Testing:** Re-run all tests after the changes to prove that nothing has broken.
